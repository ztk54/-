1. 指针的大小：
   指针变量的大小（存放地址的空间）与指针的数据类型无关，只与运行的环境有关，32位的环境下指针大小是4个字节，在64位环境下指针大小是8个字节。那么会有人问指针类型还有什么意义呢？
2. 指针类型的意义：
	* 指针类型决定了在其解引用的时候访问**几个字节**
	* 进行整数加减法的时候移动的**步长不同**，如对char类型的指针+1跳过2个字节，double类型跳过4个字节
	* void * 类型的指针可以用来接受任意类型的指针，不过他不能进行加减整数操作也不能进行解引用（因为他不知道自己要去访问几个**字节**）
3. 指针的运算：
	* 指针的加减整数运算
	* 指针减指针，可以得到两个指针之间的元素个数，不过两个指针必须指向**同一片地址**
	* sizeof的返回值要用`size_t len=strlen(arr)`的形式及，输出用%zd输出，数组名是数组首元素的地址
	* 指针的关系运算，指针的地址也是从小到大依次增大的
4. const与指针的关系
    const在c语言中修饰变量称之为常变量，其本质核心仍然为一个变量
   * const int * p类型的指针，这里可以看作const修饰* p，所以不可以通过对指针解引用来**修改变量的值**，但是可以**改变指针的指向**，也就是指针可以重新指向其他的内存空间。
   * int * const p类型的指针，这里可以看作const修饰p，因此可以通过对指针解引用来**修改变量的值**，不过不能修改指针的指向。
5. 野指针：
	1. 指针变量未初始化：
	  `int *p;*p=20;`这里没有对指针初始化一个明确的地址，也就是所谓的野指针
	2. 指针指向的空间已经被销毁：
	  ```c
	       int *test()
	       {
		       int n=100;
		       printf("%d",n);
		       return &n;
	       }
	       int main()
	       {
		       int *p=test();
		       printf("%d",*p);
	       }
	  ```
	  这里调用完test函数之后即被销毁，因此传递的地址根本*不存在*，所以不能在下面的函数中打印出正确的大小
	3. 指针越界访问：譬如指针指向的位置超出数组的范围，就会造成非法访问，因此这个指针会指向不属于其的一块空间。
	4. 总而言之当指针指向的内存空间不属于当前程序就会形成野指针。
	>[!tips]
	>如何去避免空指针。使用NULL进行判断，如`int *p=NULL;if(p!=NULL){*p=20}`先对指针赋予空指针（不能进行解引用使用），当该指针有一个**明确的指向**之后再对该指针进行操作引用。
	>当指针已经不再使用的时候可以直接当指针重置为空指针，防止后续野指针的产生。
	>尽量不返回局部变量的地址。

6. 使用断言来替代if语句来控制空指针：
   引入`#include <assert.h>`，如果想要避免空指针，条件为真的时候不会有任何影响，但是条件为假会进行**报错**。`int *p=NULL;assert(p!=NULL);`这里的条件为假，所以会报错，可以用来进行调试使用。如果确认没有出现错误，那么可以使用宏定义来使断言失效，在`#include <assert.h>`前面加上`#NDEBUG`即可。
7. 传值调用和传址调用：
   在调用函数（如简单的交换两个数字的函数）在函数内交换数值并**不会影响**主函数内的数值，这也就是所谓的传值调用。这时候我们就可以使用指针的形式修改函数内的数值，也就是传址调用，传址调用可以在函数与主函数之间建立真正的联系，在函数内部就可以修改主函数内部变量的大小。
8. 数组名的理解：
	1. 一维数组数组名，譬如数组arr[3]这样一个数组，arr代表数组中首元素地址，其与`&arr[0]`实际上是等价的。`&arr`虽然与前两者在地址上显示是一样的，但是实际上`&arr`是整个数组的地址，其+1跳过的是**整个数组**，其他两个+1只会跳过数组内的一个元素。所以我们根据这个特性就可以计算出数组内元素的个数`int sz=sizeof(arr)/sizeof(arr[0])`
	2. > [!tips]
	   这里注意我们不能在**外部函数**内使用上述方法来求函数内元素的多少，如下述程序。
	   ```c
	   int number(int arr[])
		{
			return sizeof(arr) / sizeof(arr[0]);
		}
	   int main()
		{
			int arr[] = { 1,2,3,4,5,6,7,8 };
			printf("%d\n", number(arr));
			return 0;
		}
	   ```
	   上述输出结果为2，与我们预计的大不相同，这是由于在函数的形参中编译器并不会为其专门开辟一块内存空间，所以这里的arr实际上只是**指针变量**，在我们当前环境下指针变量是8个字节，因此结果就为2。
	3. 二维数组数组名，与一维数组类似，arr也表示的是首元素的地址（不过这里的首元素是一个一维数组），同理arr与`&arr[0]`等价，都表示一个**一维数组**，`&arr`指向整个二维数组。
9. 使用指针来访问数组：
   我们知道一维数组的数组名就是数组的**首元素地址**，因此实际上在编译器中计算机是将数组处理为**指针**的形式进行处理的。也就是`arr[i]`等价于`*(arr+i)`，在scanf函数输入的时候可以写作`arr+i`更简洁的写法，这里的`arr+i`本身就是地址**不需要**再进行取地址操作。
   > [!tips]
   > 根据上述原理我们可以写出很多很有趣的写法，譬如数组arr[10]，我们先`int *p =arr`操作，之后就可以完全通过指针对数组进行操作。例如`p[i]`，`i[p]`这种奇葩写法也都是完全合理的。后着是由于编译中会自动写作`*(i+p)`的形式，与前者是完全等价的
   
10. 冒泡排序：
    ```c
    int main()
	{
		int arr[] = { 9,8,7,6,5,4,3,2,1 };
		int sz = sizeof(arr) / sizeof(arr[0]);
		for (int i = 0;i < sz;i++)
		{
			for (int j = 0;j < sz - 1 - i;j++)
			{
				if (arr[j] > arr[j + 1])
				{
					int tem = arr[j];
					arr[j] = arr[j + 1];
					arr[j + 1] = tem;
				}
			}
		}
		for (int i = 0;i < sz;i++)
		{
			printf("%d ", arr[i]);
		}
		return 0;
	}
    ```
这里的程序看似十分完美得到了正确的结果，但是倘若数组是1，2，3，4，5，6这样的正序数组，那我们不就是白白遍历比较了呢，因此我们使用标志值的方法来进行解决这个问题。
```c
int main()
{
	int arr[] = { 9,8,7,6,5,4,3,2,1 };
	int sz = sizeof(arr) / sizeof(arr[0]);
	for (int i = 0;i < sz;i++)
	{
		int flag = 1;
		for (int j = 0;j < sz - 1 - i;j++)
		{
			if (arr[j] > arr[j + 1])
			{
				int tem = arr[j];
				arr[j] = arr[j + 1];
				arr[j + 1] = tem;
				flag = 0;
			}
		}
		if (flag)
		{
			break;
		}
	}
	for (int i = 0;i < sz;i++)
	{
		printf("%d ", arr[i]);
	}
	return 0;
}
```
