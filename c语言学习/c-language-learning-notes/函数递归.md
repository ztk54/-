这是学完[[函数]]之后一个进阶的功能
1. 使用递归顺序输出数字每一位
	核心思想是递归加回退
```c
	#define _CRT_SECURE_NO_WARNINGS
	#include <stdio.h>
	void Print(int n)
	{
		if (n > 9)
		{
			Print(n / 10);
		}
		printf("%d ", n % 10);
	}
	int main()
	{
		int n;
		scanf("%d", &n);
		Print(n);
	}
```
> [!tips]
> 这里我最开始的想法是有一定问题的，这里有递归和回退两个部分。假如说输入为1234，使用会不断调用Print函数直到n为1，这时候输出1，然后回退到上次递归（即n为12的时候，然后输出12%10的值，即2）依次类推。**函数执行是线性的，因此执行过的if判断语句在回退的时候不会再次进行判断**

2. 递归实现斐波那契问题
	```c
		int Fib(int n)
		{
			if(n<=2)
				return 1;
			else 
				return Fib(n-1)+Fib(n-2);
		}
		int main()
		{
			int n=0;
			scanf("%d",&n);
			int ret=Fib(n);
			printf("%d",ret);
			return 0;
		}
	```
> [!bug]
> 这里的代码显然易见十分简洁，但是当我们输入一个稍大点的数字，例如50，会发现程序会一直执行，这是由于每次递归调用函数都要在内存中的栈区申请一块内存空间来保存函数调用中产生的各种局部变量的值，这块空间被称为运行时堆栈，或者叫做函数栈帧。递归中函数不返回，对应的函数栈帧就会一直被占用，直到递归不再继续才会开始释放栈帧空间。


因此我们不能盲目使用函数递归，需要去考虑递归和迭代（即循环）来进行解决问题。
```c
		int Fib(int n)
		{
			int a=1;
			int b=1;
			int c=0;
			while(n>2)
			{
				c=a+b;
				a=b;
				b=c;
				n--;
			}
		}
		int main()
		{
			int n=0;
			scanf("%d",&n);
			int ret=Fib(n);
			printf("%d",ret);
			return 0;
		}
```
