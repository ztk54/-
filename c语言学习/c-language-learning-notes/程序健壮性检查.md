这里用scanf检查健壮性一定要使用getchar清空缓冲区，不然会造成程序死循环。
2. ```c
   int main()
{
	int count = 0;
	int j = 0;
	for (int i = 0;i <= 100000;i++)
	{
		j = is_shuixian(i);
		if (j == 1)
		{
			printf("%d ", i);
			count++;
		}
		if (count % 5 == 0 && count != 0)
		{
			printf("\n");
		}
		if (i == 100000)
		{
			printf("\n");
		}
	}
	printf("一共有%d个水仙花数\n", count);
	return 0;
}
   ```
我们看上述代码，本身我的想法是每输出5个水仙花数就换行一次，但是上面代码的结果却是满屏的回车换行，这里举个例子吧，比如说我已经找到10个水仙花数，但是接下来100个数字都不是水仙花数，那么count始终为10，满足条件一直输出换行。所以正确的写法应该是每找到一个水仙花数，才进行条件判断是否换行。
