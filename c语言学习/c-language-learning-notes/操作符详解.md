1. 进制与进制转化：
	十进制转化为二进制可以用整除法，依次除2，得到的余数就是从高到低写下来就是对应二进制。二进制转化八进制，**从右向左**每三位对应八进制中的一位，用这个方法就能正确转化为八进制。同理，二进制转化为十六进制也了类似，十六进制一般以0x开头。
2. 原码，反码，补码：
	1. 有符号整数二进制的最高位被认为是符号位，1表示负数，0表示正数。而无符号整数不存在符号位。一个字节是八个比特位。
	2. 正数和无符号整数的原，反，补码相同。
	3. 负数的原码就是其二进制序列，反码为符号位不变，其他位置取反，补码是将反码加一，
	   补码直接取反加一就可以直接得到原码。
	整数在内存中是以补码形式存放，但是在**打印或者呈现**的时候是以原码形式。
3. 移位操作符（**只能用于整数**，字符也属于整形）
   <<左移操作符，对补码进行操作，右边用零填充，左边抛弃。
   左移n位相当于对这个数乘以2的n次方，右移n位相当于对这个数除以2的n次方（由于除法可能虎会出现小数的情况，因此应该同时向下取整）
   ```c
    #define _crt_secure_no_warnings
	#include <stdio.h>
	int main()
	{
		int num = 10;
		int r = num << 1;
		printf("r=%d\n", r);
		printf("num=%d", num);
		return 0;
}
   ```
	这里的输出中r为20，num为10，所以过程中左移操作符并不会改变num的值。负数首先要转化为补码，然后进行左移运算，不过在输出的时候务必转化为原码。
   `>>`右移操作符。分为算数右移（更常见）和逻辑右移，算数右移会保持原本的符号位，而逻辑右移则是右边抛弃，左边补零
4. 位操作符：针对补码进行操作
	1. 按位与&：对应二进制有零则为零，同时为1才为1。
	  找出一个数字（包含负数）二进制数据中1的个数
		```C
			int num = 0;
			scanf("%d", &num);
			int count = 0;
			for (int i = 0;i < 32;i++)
			{
				if (((num >> i)&1) == 1)
				{
					count++;
				}
			}
			printf("%d", count);
			或者用一种更简洁的方式；
				while (num)
				{
					num = num & (num - 1);
					count++;
				}
		```
	
	
	     按照这个方法我们还可以判断一个数字是否为2的次方，即判断其二进制编码是否只有一个‘1’即可。
	2. 按位或|：对应有1则为1，同时为零才为零。（算出来负数的补码要转化为原码才能够呈现）
	3. 按位异或^：相异为1，相同为零。
		`a^a=0 a^0=a 3^a^5=5 3^5^3=5`异或支持交换律。
		> [!tips]
		> 假如说不允许创建第三个变量来交换两个变量，这时候我们就可以使用异或来实现
		> ` a=a^b;b=a^b;b=a^b`
		> 这里首先`b=a^b^b`其中`b^b=0`而且0^任何数都为其本身。
		
		假如说要找出一堆数字中唯一出现一次的数字（其他皆出现两次）就可以使用异或思想，把所有数字全部使用异或操作，最后得出的结果即是唯一出现的。
		
	 4. 按位取反~：二进制相反。
5. sizeof和逗号表达式：
	  * sizeof括号内的表达式不参与实际运算，例如`sizeof(n+9)`这里并不会对n的值进行改变，sizeof计算出来的是对应元素所占用的字节大小
	  * 逗号表达式的结果是最后一个逗号后的表达式，前面的会进行运算，但是不是最终结果。
	  * sizeof与strlen的差别：strlen会统计'\0'前面的字符个数（**不包括'\0'**），不会关心存放的数据类型，如果没有遇到\0则会生成一个随机数，如`char arr[]={'a','b','c'};int a=strlen(arr)`这时候就不能得到正确的值。

7. 整形提升：
   ```c
	   char a=10;
	   char b=120;
	   char c=a+b;
	   printf("%d",c);
   ```
这里按照我们的直觉来看，输出结果应该为120，但是实际上char只有一个字节，因此范围为-128~127，所有这里会发生一些问题，实际上输出结果为-126，这里就要用到整型提升这个知识。
> [!tips]
> C语言中整型算术运算总是至少以缺省(默认)整型类型的精度来进行的。
为了获得这个精度，表达式中的字符和短整型操作数在使用之前被转换为普通整型，这种转换称为**整型提升**。
整型提升的意义：
表达式的整型运算要在CPU的咱应运算器件内执行，CPU内整型运算器(ALU)的操作数的字节长度一般就是int的字节长度，同时也是CPU的通用寄存器的长度，
因此，即使两个char类型的相加，在CPU执行时实际上也要**先转换**为CPU内整型操作数的标准长度，
通用CPU(generai-purpose CPU)是难以直接实现两个8比特字节直接相加运算(虽然机器指令中可能有这种字节相加指令)。所以，表达式中各种长度可能小于int长度的整型值，都必须先转换为**int或unsigned int**，然后才能送入CPU去执行运算


首先我们写出来10和120的二进制序列，10为`00000000 00000000 00000000 00001010`，120为`00000000 00000000 00000000 01111000`，但是由于char类型只有**8个比特位，所以发生截断现象**，因此实际上a存放为`00001010`，b存放为`01111000`。但是这时候我们要进行a+b的运算，但是由于二者均为char类型，所以会发生整型提升。
> 整形提升中，有符号的是按照其本身符号位来提升的，无符号的高位补0，因此在**计算中**a为`00000000 00000000 00000000 00001010`，
> b为`00000000 00000000 00000000 01111000`。

a+b结果的二进制形式为`00000000 00000000 00000000 10000010`，然后存入c中再次发生截断，c的存放为`10000010`，然后我们在打印的时候再次遵循整型提升，打印时的补码为`11111111 11111111 11111111 10000010`，取反（**取反的时候符号位不变**）加一得到原码为`10000000 00000000 00000000 01111110`所以结果为-126。
