## ctype头文件
ctype是c语言标准库中的字符处理头文件，提供了一些列字符分类和转换函数，主要用来判断字符类型，以及进行大小写转换，其用法区别并不大，接下来以`islower()和isupper()`两个为例进行讲解。
* `islower()`用于判断一个字符是否为小写字符，是的话返回一个非零数字
* `isupper()`用于判断一个字符是否为大·写字符，是的话返回一个非零数字
* `isalunm()`检查是否为数字或字母，`isalpha`检查是否为字母，`isdigit()`检查是否为十进制数字，`isxdigit()`检查是否为十六进制数字，`isspace()`检查是否为空白字符。
* `tolower()`和 `toupper()`前者为大写转换为小写，后者为小写转换为大写。
## stlen函数
strlen函数的返回类型是size_t是一种**无符号整形**(使用%zd进行打印)，容易出错，函数原型为`size_t strlen (const char *str)`，strlen函数主要用于计算字符串的长度（**不包含**终止字符`\0`），因此这里会出现几种strlen的易出现的错误：
* 用于没有以`\0`结尾的字符数组，譬如对字符数组`char str[15]={'H','e','l','l','o'}`使用strlen函数的时候由于没有结束标志词`\0`会导致产生一个随机值。
* 对字符数组不完全初始化，`char str2[20];str2[0]='H';str2[1]='i';`这里数组内剩下8个元素未进行初始化，不能找到`\0`。
strlen函数的多种模拟实现方法：
```c
size_t count_strlen(const char* str)
{
    assert(str);
    int count = 0;
    while (*str)
    {
        str++;
        count++;
    }
    return count;
}
size_t pointer_strlen(const char* str)
{
    assert(str);
    const char* start = str;
    while (*str) 
    {
        str++;
    }
    return str - start;
}
```
## strcpy函数
strcpy函数原型为`char *strcpy(char *dest,const char *src);`其中dest是目标字符串指针，src是原字符串指针，指向需要复制的字符串。
常见出现的几种错误方式：
* 目标缓冲区大小不足`char des[5];const char *src="Hello world";strcp(dest,src);`由于dest空间不足，导致不能完成字符串复制功能，在使用strcpy函数的时候一定要保证有充足的空间。
* 重叠的内存空间复制`char str[20]="Hello world";strcpy(str,str+7);`这里发生了字符串复制的内存重叠行为，在strcpy函数中这是不允许的存在，不过可以使用内存操作函数memove完成上述操作。
* 字符串结尾没有\0，使用未进行初始化的指针。
* 使用strcpy复制非字符串数据。
模拟实现：
```c
char* my_strcpy(char* dest, const char* src)
{
    assert(dest && src);
    char* tem = dest;
    while (*tem++ = *src++);
    return dest;
}
```
