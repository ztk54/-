二分查找是用于实现**升序数组**查询某一元素的策略，代码如下：
```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
int main()
{
	int arr[] = { 1,3,4,6,8,12,15,16,18,19,20 };
	int left = 0, right = sizeof(arr) / sizeof(arr[0]) - 1;
	int flag = 0;
	int number = 1;
	printf("请您输入您想查找的数据\n");
	scanf("%d", &number);
	while (left <= right)
	{
		int mid = (left + right) / 2;//int mid=left+(right-left)/2;
			if (arr[mid] > number)
			{
				right = mid - 1;
			}
			else if (arr[mid] < number)
			{
				left = mid + 1;
			}
			else
			{
				printf("找到了，下标为：%d\n", mid);
				flag = 1;
				break;
			}
	}
	if (flag == 0)
	{
		printf("找不到这个数字\n");
	}
	return 0;
}
```
>[!tips]
>这里我犯了两个很严重的错误，导致代码出现了一些问题。
>1. 首先我忘记了在循环内部更新mid的大小，导致mid数值不会发生更新，因此没有实现二分查找的功能实现。
>2. 其次我为数组开创了40个int元素的空间，但是实际上只使用了一小部分，导致在sizeof那里计算right的时候出现了一些问题。
>3. left=mid-1;而right=mid+1;两个有一定的不同


>[!warning]
>在这里计算mid的时候，可能会发生左值加右值大于数据类型的范围的情况，因此我们可以使用`mid=left+(right-left)/2`来计算mid的大小，这样子就避免了数据溢出的问题。

查找素数：
```c
bool is_prime(int n)
{
	if (n <= 1)return false;
	if (n <= 3)return true;
	if (n % 2 == 0 || n % 3 == 0)return false;
	int limit = sqrt(n);
	for (int i = 5;i <= limit;i += 6)
	{
		if (n % i == 0 || n % (i + 2) == 0)
		{
			return false;
		}
	}
	return true;
}
```
首先1不是素数要单独划分出来，其次只需要遍历到**根号n**的位置即可（数学方法可证明），并且所有的整数都可以表示为6k， 6k+1，6k+2，6k+3，6k+4，6k+5这六种形式，而其中四种情况都可以确定其不是素数，所以这意味着所有大于3的素数必定为6k+1或者6k-1的形式（**反过来并不成立**），由于我们已经检察过2和3两种情况，那么倘若一个数字不存在6k+1或者6k-1两种形式的因子，那么他一定是素数。
