## 结构体初始化
对于结构体进行初始化
```c
struct stu//这里的stu相当于一个tag
{
	char name[20];
	int age;
	float score;
};
int main()
{
	struct stu S1={“zhangsan”,17,80.3};
}
```
使用typedef对结构体初始化
```c
typedef struct Stu
{
	char name[20];
	int age;
	float score;	
}stu;
int main()
{
	stu s1={“zhangsan”,17,80.3};
}
```
## 结构体的自引用
结构体的自引用是指结构体内部包含指向自身类型结构体的指针，常用于链表、树等数据结构
```c
typedef struct ListNode
{
	int data;
	struct ListNode *next;
}ListNode;
```
注意这里在定义的结构体里面的不能直接用ListNode来创建* next，这是由于在结构体里面typedef还没有生效，因此不能这样子创建。
## 结构体内存对齐
结构体在分配内存空间的时候会存在内存浪费现象，其中存在对齐数的影响
* 对齐数=编译器默认的一个对齐数与该成员变量大小的较小值：在vs（mscv）中默认对齐数为8，linux和gcc没有对齐数，对齐数就是成员自身的大小。
* 结构体的总大小为最大对齐数（结构体中的每个成员变量都有一个对齐数，所有对齐数中最大的）的整数倍。
* 如果结构体里面嵌套了一个结构体，嵌套的结构体对齐到自己成员中最大对齐数的整数倍，结构体的整体大小就是所有最大对齐数（含嵌套结构体成员中的对齐数）的整数倍。
