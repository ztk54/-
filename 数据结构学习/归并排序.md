# 当数据放不进内存时怎么办？用 C 语言实现简化版外部排序

## 1. 前言：为什么需要外部排序？

在学习普通排序算法时，我们通常默认所有数据都可以放进内存中，例如用一个数组保存所有元素，然后直接进行快速排序、堆排序或归并排序。

但如果现在有上亿个整数需要排序，数据量已经大到无法一次性全部加载进内存，该怎么办？

这时就需要用到**外部排序**。外部排序的核心思想是：先将大文件分成多个小块，每次只读入一部分数据到内存中排序，然后再利用归并的思想，把这些有序小文件逐步合并成一个完整的有序文件。

在深入外部排序之前，我们不妨先回顾一下普通归并排序的实现。

---

## 2. 先回顾普通归并排序

### 2.1 归并排序的核心思想

归并排序是一种典型的分治算法，核心可以概括为三步：

1. **分解**：将数组不断二分，直到每个子区间只有一个元素；
2. **解决**：单个元素天然有序；
3. **合并**：将两个有序区间合并成一个更大的有序区间。

时间复杂度 O(n log n)，空间复杂度 O(n)（需要额外的临时数组）。

### 2.2 归并排序代码实现

> 下面代码需要包含 `stdio.h`、`stdlib.h`，外部排序部分还需要 `time.h`。

```c
void _Merge_sort(int* arr, int left, int right, int* tmp)
{
    if (left >= right)
        return;

    int mid = (right - left) / 2 + left;
    _Merge_sort(arr, left, mid, tmp);
    _Merge_sort(arr, mid + 1, right, tmp);

    int begin1 = left, end1 = mid;
    int begin2 = mid + 1, end2 = right;
    int index = begin1;

    while (begin1 <= end1 && begin2 <= end2)
    {
        if (arr[begin1] <= arr[begin2])
            tmp[index++] = arr[begin1++];
        else
            tmp[index++] = arr[begin2++];
    }

    while (begin1 <= end1)
        tmp[index++] = arr[begin1++];
    while (begin2 <= end2)
        tmp[index++] = arr[begin2++];

    for (int i = left; i <= right; i++)
        arr[i] = tmp[i];
}

void Merge_sort(int* arr, int n)
{
    int* tmp = (int*)malloc(n * sizeof(int));
    if (tmp == NULL)
    {
        perror("Malloc Failed");
        return;
    }
    _Merge_sort(arr, 0, n - 1, tmp);
    free(tmp);
}
```

> 写合并逻辑时有一个容易踩的坑：合并时应该把**原数组**中的元素放入**临时数组**，即 `tmp[index++] = arr[begin1++]`，而不是反过来写。把 `arr` 和 `tmp` 的位置弄反是新手常犯的错误。

### 2.3 普通归并排序的局限

普通归并排序虽然时间复杂度稳定为 O(n log n)，但它有一个明显前提：**待排序数据需要全部存放在内存中**。

同时，归并排序在合并过程中还需要额外的临时数组 `tmp`，空间复杂度为 O(n)。当数据量非常大，例如几千万甚至上亿个整数时，内存可能无法一次性容纳全部数据。这个时候，就不能再简单地开一个大数组来排序，而需要借助磁盘文件完成排序——这就是外部排序的应用场景。

---

## 3. 外部排序的基本思想

### 3.1 什么是外部排序

外部排序，简单来说就是**数据在磁盘上、排序在内存中**。核心流程围绕三个关键词：

1. **分块读取**：每次从大文件中读取一部分数据到内存；
2. **块内排序**：对这一小块数据使用内部排序算法（例如 `qsort`）；
3. **文件归并**：将排好序的小块写入临时文件，再把多个有序临时文件归并成最终有序文件。

### 3.2 本文实现的说明

> 本文实现的是一个**简化版外部排序**。它的思路是维护一个已经有序的大文件 `file1`，每次从原始数据文件中读取一段新数据，排序后写入 `file2`，再将 `file1` 和 `file2` 归并成新的有序文件。
>
> 这种方式便于理解外部排序思想，但如果数据量特别大，前面已经合并好的数据会被反复读写。更高效的外部排序通常会先生成多个有序段，然后进行多轮二路归并或多路归并。
>
> 另外，为了方便观察和调试，本文将整数以文本形式写入文件，每个整数占一行。实际工程中，如果追求更高的读写效率，也可以使用二进制文件进行存储。

### 3.3 文件作用说明

本文中用到以下几个文件：

| 文件 | 作用 |
|------|------|
| `data.txt` | 保存原始无序数据 |
| `file1.txt` | 保存当前已经归并好的有序数据 |
| `file2.txt` | 保存新读取并排序后的一段有序数据 |
| `mfile.txt` | `file1` 和 `file2` 归并后的临时结果文件 |

### 3.4 整体流程图

```text
data.txt 原始数据
      |
      | 每次读取 n 个整数
      v
  内存数组 arr
      |
      | qsort 排序
      v
生成有序段 file1 / file2
      |
      | MergeFile 归并
      v
    mfile.txt
      |
      | 重命名为 file1.txt
      v
继续读取下一段数据并归并
```

## 4. 主函数逻辑

主函数的流程如下：

1. 生成测试数据 `data.txt`；
2. 先读取第一段数据，排序后写入 `file1`；
3. 再读取下一段数据到 `file2`，如果读到了数据，将 `file1` 和 `file2` 归并成 `mfile`；
4. 删除旧的 `file1` 和 `file2`，将 `mfile` 重命名为 `file1`；
5. 重复步骤 3-4，直到 `data.txt` 中没有新的数据可读。

循环结束后，最终的排序结果保存在 `file1.txt` 中。

```c
int main()
{
    Create_number();

    int number = 200;
    const char* file1 = "file1.txt";
    const char* file2 = "file2.txt";
    const char* mfile = "mfile.txt";

    FILE* fout = fopen("data.txt", "r");
    if (fout == NULL)
    {
        perror("Open Failed");
        return 1;
    }

    int ret1 = ReadNumSort(fout, number, file1);
    if (ret1 == 0)
    {
        fclose(fout);
        return 0;
    }

    while (ReadNumSort(fout, number, file2) != 0)
    {
        MergeFile(file1, file2, mfile);
        remove(file1);
        remove(file2);
        rename(mfile, file1);
    }

    fclose(fout);
    return 0;
}
```

## 5. 生成测试数据：Create_number

`Creat_number` 负责生成随机整数并写入 `data.txt`，为后面的排序提供原始数据。

```c
void Create_number()
{
    int n = 1000;
    srand((unsigned int)time(0));
    const char* file = "data.txt";

    FILE* fout = fopen(file, "w");
    if (fout == NULL)
    {
        perror("Create Failed");
        return;
    }

    for (int i = 0; i < n; i++)
    {
        int x = rand() +i;
        fprintf(fout, "%d\n", x);
    }

    fclose(fout);
}
```

## 6. 分块读取并排序：ReadNumSort

`ReadNumSort` 从原始数据文件中读取最多 `n` 个整数到内存数组，排序后写入指定文件。函数返回实际读取的元素个数，当返回 0 时表示 `data.txt` 中的数据已被全部读完。

这里块内排序直接使用 C 标准库中的 `qsort`，因为本文重点是外部排序流程，而不是重复实现内部排序算法。当然，也可以把这里的 `qsort` 替换成前面实现的 `Merge_sort`。

```c
int compare(const void* elem1, const void* elem2)
{
    int a = *(const int*)elem1;
    int b = *(const int*)elem2;
    if (a > b)  return 1;
    if (a < b)  return -1;
    return 0;
}

int ReadNumSort(FILE* fout, int n, const char* file)
{
    int* arr = (int*)malloc(n * sizeof(int));
    if (arr == NULL)
    {
        perror("Malloc Failed");
        return 0;
    }

    int j = 0;
    int x = 0;
    for (int i = 0; i < n; i++)
    {
        if (fscanf(fout, "%d", &x) != 1)
            break;
        arr[j++] = x;
    }

    if (j == 0)
    {
        free(arr);
        return 0;
    }

    qsort(arr, j, sizeof(int), compare);

    FILE* fin = fopen(file, "w");
    if (fin == NULL)
    {
        perror("Open Failed");
        free(arr);
        return 0;
    }

    for (int i = 0; i < j; i++)
        fprintf(fin, "%d\n", arr[i]);

    free(arr);
    fclose(fin);
    return j;
}
```

## 7. 合并两个有序文件：MergeFile

`MergeFile` 是外部排序的核心。可以把 `MergeFile` 理解成普通归并排序中"合并两个有序数组"的**文件版本**：普通归并排序用两个下标遍历两个有序区间，而这里用两个文件读取指针分别读取 `file1` 和 `file2` 中的当前元素，逐个比较后将较小的写入 `mfile`。归并结束后，再将剩余元素写入。

```c
void MergeFile(const char* file1, const char* file2, const char* mfile)
{
    FILE* fout1 = fopen(file1, "r");
    FILE* fout2 = fopen(file2, "r");
    FILE* mfout = fopen(mfile, "w");

    if (fout1 == NULL || fout2 == NULL || mfout == NULL)
    {
        perror("Open Failed");
        if (fout1) fclose(fout1);
        if (fout2) fclose(fout2);
        if (mfout) fclose(mfout);
        return;
    }

    int x1 = 0, x2 = 0;
    int ret1 = fscanf(fout1, "%d", &x1);
    int ret2 = fscanf(fout2, "%d", &x2);

    while (ret1 == 1 && ret2 == 1)
    {
        if (x1 <= x2)
        {
            fprintf(mfout, "%d\n", x1);
            ret1 = fscanf(fout1, "%d", &x1);
        }
        else
        {
            fprintf(mfout, "%d\n", x2);
            ret2 = fscanf(fout2, "%d", &x2);
        }
    }

    while (ret1 == 1)
    {
        fprintf(mfout, "%d\n", x1);
        ret1 = fscanf(fout1, "%d", &x1);
    }
    while (ret2 == 1)
    {
        fprintf(mfout, "%d\n", x2);
        ret2 = fscanf(fout2, "%d", &x2);
    }

    fclose(fout1);
    fclose(fout2);
    fclose(mfout);
}
```

## 8. 代码中容易踩的坑

这一节整理了几个在实际编码中容易遇到的问题。

### 8.1 `fopen` 中 `"r"` 和 `"w"` 的区别

- `"r"` 是只读打开，文件不存在会打开失败。
- `"w"` 是写入打开，如果文件已经存在，**会清空原文件内容**。

所以在归并 `file1` 和 `file2` 时，两个输入文件必须用 `"r"` 打开，而输出文件 `mfile` 才能用 `"w"` 打开。如果不小心对输入文件用了 `"w"`，文件内容会被直接清空，丢失数据。

### 8.2 文件使用完后要 `fclose`

如果打开文件后不关闭，可能导致数据没有及时写入磁盘，也会造成资源泄漏。

### 8.3 `malloc` 后要 `free`

`ReadNumSort` 中动态开辟了数组 `arr`，使用完后必须 `free`。

### 8.4 `fscanf` 不建议只判断 `EOF`

更稳妥的写法是判断返回值是否为 `1`（成功读取一个数据项），而不是判断 `== EOF`。因为 `fscanf` 在遇到格式不匹配时也可能返回其他非 `1` 的值，只判断 `EOF` 可能导致死循环。

### 8.5 `qsort` 比较函数不要直接相减

直接 `return *(int*)elem1 - *(int*)elem2` 在极端情况下可能整数溢出。建议用分支判断后返回 `-1`、`0`、`1`。

### 8.6 注意文件操作的返回值

`remove` 和 `rename` 都可能执行失败，例如文件不存在、权限不足或文件仍被占用。实际项目中应该检查它们的返回值，避免文件状态异常。本文为了突出外部排序流程，主函数中未做过多错误处理。

### 8.7 文本文件与二进制文件的区别

本文为了方便观察结果，使用文本文件保存整数，每个整数占一行。文本文件可读性强，但读写效率相对较低。如果数据规模更大，可以考虑使用二进制文件提高 I/O 效率。

## 9. 当前实现的局限与优化方向

本文实现的是一个简化版外部排序，适合理解基本思想，但仍然存在一些不足：

1. **反复读写**：每次都将当前已经归并好的 `file1` 和新生成的 `file2` 重新归并，导致 `file1` 中的数据被反复读写。当数据量很大时，磁盘 I/O 开销较高。

   更标准的二路外部归并通常会先生成多个有序段，然后多轮两两归并：

   ```text
   data.txt
     ↓
   run0.txt  run1.txt  run2.txt  run3.txt
     ↓
   run0 + run1 → run01
   run2 + run3 → run23
     ↓
   run01 + run23 → result.txt
   ```

   这样可以减少同一批数据被反复读写的次数。

2. **二路归并**：本文每次只合并两个文件。实际外部排序中，常常会使用**多路归并**，一次合并多个有序段，从而减少归并轮数。

3. **文件管理简陋**：如果需要处理更多有序段，可以使用数组保存多个临时文件名，或者按 `run0.txt`、`run1.txt` 的方式自动生成文件名。

4. **排序算法固定**：块内排序固定使用 `qsort`，可以根据数据特点选择更合适的内部排序算法。

后续可以继续优化为：先生成多个有序小文件，再进行多轮二路归并，或者使用败者树实现多路归并。

---

## 10. 总结

归并排序的核心是"分而治之"：先将问题拆小，再将有序子区间合并。

当数据量较小时，普通归并排序可以直接在内存中完成；但当数据量大到无法一次性放入内存时，就需要借助外部排序。外部排序的核心思路可以概括为：**分块读取、块内排序、文件归并**。

本文通过一个简化版实现，演示了如何将大文件中的数据分批读入内存排序，再利用归并思想将多个有序文件合并成最终有序文件。理解了这个过程之后，再去学习多路归并、败者树等更高效的外部排序实现，就会容易很多。

## 11. 完整代码

上文为了便于讲解，将代码拆成了多个函数分段展示。以下是完整可运行的代码，包含所有头文件和函数。

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

// ---------- 普通归并排序 ----------
void _Merge_sort(int* arr, int left, int right, int* tmp)
{
    if (left >= right)
        return;

    int mid = (right - left) / 2 + left;
    _Merge_sort(arr, left, mid, tmp);
    _Merge_sort(arr, mid + 1, right, tmp);

    int begin1 = left, end1 = mid;
    int begin2 = mid + 1, end2 = right;
    int index = begin1;

    while (begin1 <= end1 && begin2 <= end2)
    {
        if (arr[begin1] <= arr[begin2])
            tmp[index++] = arr[begin1++];
        else
            tmp[index++] = arr[begin2++];
    }
    while (begin1 <= end1)
        tmp[index++] = arr[begin1++];
    while (begin2 <= end2)
        tmp[index++] = arr[begin2++];

    for (int i = left; i <= right; i++)
        arr[i] = tmp[i];
}

void Merge_sort(int* arr, int n)
{
    int* tmp = (int*)malloc(n * sizeof(int));
    if (tmp == NULL)
    {
        perror("Malloc Failed");
        return;
    }
    _Merge_sort(arr, 0, n - 1, tmp);
    free(tmp);
}

// ---------- 外部排序 ----------
void Create_number()
{
    int n = 1000;
    srand((unsigned int)time(0));
    const char* file = "data.txt";

    FILE* fout = fopen(file, "w");
    if (fout == NULL)
    {
        perror("Create Failed");
        return;
    }
    for (int i = 0; i < n; i++)
    {
        int x = rand() +i;
        fprintf(fout, "%d\n", x);
    }
    fclose(fout);
}

int compare(const void* elem1, const void* elem2)
{
    int a = *(const int*)elem1;
    int b = *(const int*)elem2;
    if (a > b)  return 1;
    if (a < b)  return -1;
    return 0;
}

int ReadNumSort(FILE* fout, int n, const char* file)
{
    int* arr = (int*)malloc(n * sizeof(int));
    if (arr == NULL)
    {
        perror("Malloc Failed");
        return 0;
    }

    int j = 0;
    int x = 0;
    for (int i = 0; i < n; i++)
    {
        if (fscanf(fout, "%d", &x) != 1)
            break;
        arr[j++] = x;
    }

    if (j == 0)
    {
        free(arr);
        return 0;
    }

    qsort(arr, j, sizeof(int), compare);

    FILE* fin = fopen(file, "w");
    if (fin == NULL)
    {
        perror("Open Failed");
        free(arr);
        return 0;
    }
    for (int i = 0; i < j; i++)
        fprintf(fin, "%d\n", arr[i]);

    free(arr);
    fclose(fin);
    return j;
}

void MergeFile(const char* file1, const char* file2, const char* mfile)
{
    FILE* fout1 = fopen(file1, "r");
    FILE* fout2 = fopen(file2, "r");
    FILE* mfout = fopen(mfile, "w");

    if (fout1 == NULL || fout2 == NULL || mfout == NULL)
    {
        perror("Open Failed");
        if (fout1) fclose(fout1);
        if (fout2) fclose(fout2);
        if (mfout) fclose(mfout);
        return;
    }

    int x1 = 0, x2 = 0;
    int ret1 = fscanf(fout1, "%d", &x1);
    int ret2 = fscanf(fout2, "%d", &x2);

    while (ret1 == 1 && ret2 == 1)
    {
        if (x1 <= x2)
        {
            fprintf(mfout, "%d\n", x1);
            ret1 = fscanf(fout1, "%d", &x1);
        }
        else
        {
            fprintf(mfout, "%d\n", x2);
            ret2 = fscanf(fout2, "%d", &x2);
        }
    }
    while (ret1 == 1)
    {
        fprintf(mfout, "%d\n", x1);
        ret1 = fscanf(fout1, "%d", &x1);
    }
    while (ret2 == 1)
    {
        fprintf(mfout, "%d\n", x2);
        ret2 = fscanf(fout2, "%d", &x2);
    }

    fclose(fout1);
    fclose(fout2);
    fclose(mfout);
}

int main()
{
    Create_number();

    int number = 200;
    const char* file1 = "file1.txt";
    const char* file2 = "file2.txt";
    const char* mfile = "mfile.txt";

    FILE* fout = fopen("data.txt", "r");
    if (fout == NULL)
    {
        perror("Open Failed");
        return 1;
    }

    int ret1 = ReadNumSort(fout, number, file1);
    if (ret1 == 0)
    {
        fclose(fout);
        return 0;
    }

    while (ReadNumSort(fout, number, file2) != 0)
    {
        MergeFile(file1, file2, mfile);
        remove(file1);
        remove(file2);
        rename(mfile, file1);
    }

    fclose(fout);
    return 0;
}
```
